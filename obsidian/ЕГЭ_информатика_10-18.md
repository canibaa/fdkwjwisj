## 18. Робот / таблица
Динамическое программирование:
    dp = [[0] * m for _ in range(n)]
    dp[0][0] = 1
    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                continue
            if i: dp[i][j] += dp[i-1][j]
            if j: dp[i][j] += dp[i][j-1]
    print(dp[-1][-1])
Запрещённые клетки обычно получают значение 0.
