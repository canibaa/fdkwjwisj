## 11. Информационный объём

### Вариация A — алфавит
Если алфавит содержит N символов, один символ = log2(N) бит.
```python
from math import log2
i = log2(N)
I = K * i
```

### Вариация B — пароль
Количество вариантов = `N ** K`.
Если все варианты равновероятны, объём = `K * log2(N)` бит.

### Вариация C — известная часть + дополнительная информация
Считай отдельно известную и неизвестную части, затем складывай объёмы.

### Перевод
`бит -> /8 -> байты -> /1024 -> КБ -> /1024 -> МБ`.

## 16. Рекурсия — ОПТИМИЗАЦИЯ

### Метод 1 — `sys.setrecursionlimit`
Когда рекурсия глубокая и возникает `RecursionError`.
```python
import sys
sys.setrecursionlimit(1000000)
```
Важно: лимит только разрешает более глубокий стек, он не ускоряет алгоритм.

### Метод 2 — `@lru_cache`
Когда одна и та же функция вызывается для одинаковых аргументов.
```python
from functools import lru_cache
@lru_cache(None)
def f(n):
    if n == 1:
        return 1
    return n * f(n-1)
```

Пример:
```python
print(f(3038) + 5*f(3037))
```

### Метод 3 — цикл `for` вместо рекурсии
Если функция просто идёт по значениям подряд, рекурсию можно заменить циклом.
```python
ans = 1
for i in range(1, n+1):
    ans *= i
print(ans)
```

### Метод 4 — несколько рекурсивных переходов + кэш
```python
@lru_cache(None)
def f(n):
    if n <= 1:
        return 1
    return f(n-1) + f(n-2)
```

## 18. Робот в таблице

### Вариация A — количество путей только вправо/вниз
```python
dp = [[0]*m for _ in range(n)]
dp[0][0] = 1
for i in range(n):
    for j in range(m):
        if i == 0 and j == 0: continue
        if i: dp[i][j] += dp[i-1][j]
        if j: dp[i][j] += dp[i][j-1]
print(dp[-1][-1])
```

### Вариация B — запрещённые клетки
```python
if blocked[i][j]:
    dp[i][j] = 0
    continue
```

### Вариация C — минимальная/максимальная сумма
```python
dp[0][0] = cost[0][0]
for i in range(n):
    for j in range(m):
        if i == 0 and j == 0: continue
        prev = []
        if i: prev.append(dp[i-1][j])
        if j: prev.append(dp[i][j-1])
        dp[i][j] = min(prev) + cost[i][j]
```
Для максимума замени `min` на `max`.
