## 19–21. Теория игр

### Вариация A — одна куча, один ход
```python
def win(s):

    return any(not win(s+m) for m in moves)
```

### Вариация B — одна куча, два хода
```python
def win(s):
    if s >= target:
        return True
    return any(not win(s+m) for m in [1,2] for _ in [0])
```
На практике лучше явно перечислить ходы: `win(s+1)`, `win(s*2)` и т. п.

### Вариация C — две кучи
```python
def win(a, b):
    if a+b >= target:
        return True
    states = [(a+1,b), (a,b+1), (a*2,b), (a,b*2)]
    return any(not win(x,y) for x,y in states)
```

### Вариация D — выигрыш за 1 ход / 2 хода
Обычно строят функции `W`, `L`, `W2` или хранят номер хода.
```python
def win(s, moves):
    if s >= target: return True
    return any(not win(s+m, moves) for m in moves)
```

### Вариация C — делители
```python
def divisors(n):
    d = 1
    while d*d <= n:
        if n % d == 0:
            yield d
            if d*d != n:
                yield n//d
        d += 1
```

## Общая памятка сложности
- Один проход: O(N).
- Сортировка: O(N log N).
- Два вложенных прохода: O(N²) — опасно для больших N.
- Полный перебор всех слов: допустим только при небольшом пространстве вариантов.
