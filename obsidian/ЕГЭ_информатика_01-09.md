## 5. Системы счисления

### Универсальный перевод
```python
def to_base(n, base):
    s = ''
    while n:
        s = str(n % base) + s
        n //= base
    return s or '0'
```

### Вариация A — троичная, дописать последние цифры
```python
for N in range(1, 1000):
    s = to_base(N, 3)
    if N % 3 == 0:
        s += s[-2:]
    else:
        k = (s.count('1') + s.count('2')) * 3
        s += to_base(k, 3)
    R = int(s, 3)
    if 900 < R < 1000:
        print(R)
```

## 7. Объём информации

### Звук
I = k · i · f · t. После расчёта получаем биты.
```python
I = channels * depth * frequency * seconds
MB = I / 8 / 1024 / 1024
```
Моно=1 канал, стерео=2, квадро=4.

### Графика
N = 2^i, значит `i = log2(N)`.
```python
from math import log2
i = int(log2(colors))
I = width * height * i
```

### Передача
I = v · t. Если скорость в бит/с — объём тоже сначала держи в битах.
```python
I = speed * seconds
```

### Переводы
1 байт = 8 бит; 1 КБ = 1024 Б; 1 МБ = 1024 КБ.
